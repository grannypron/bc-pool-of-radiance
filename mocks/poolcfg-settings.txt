POOLCFG (#876): Game Settings (POOLOPT.CFG)

The Settings screen's Game page, line for line: the same labels, order, indent, Quick Mode heading and stepping lines (`CfgFile.SettingName`, `StepNames`, `NextSetting`), so the two can't drift. The About panel explains the highlighted setting, with its default and key.

    CHANGE              ENTER, SPACE, LEFT, RIGHT TURN A FLAG OVER;

                        AS IN THE GAME
    DEFAULT             F5 (THE HIGHLIGHTED SETTING)
    BACK                ESC
    SAVE AND EXIT       F10

Sound and Combat Log show the stored setting, not the game's state at run time. Their About text says so: "With no sound device in POOL.CFG the game stays silent whatever this says", and the EMS note shown above.

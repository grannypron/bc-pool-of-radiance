POOLCFG (#876): Game, Sound, Camp and Combat Settings (POOLOPT.CFG)

The Settings screen's Game page (and in the same way its Sound, Camp and Combat pages), line for line: the same labels, order, indent, Quick Mode heading and stepping lines (`CfgFile.SettingName`, `StepNames`, `NextSetting`), so the two can't drift. The About panel explains the highlighted setting, with its default and key.

Sound and Combat Log show the stored setting, not the game's state at run time. Their About text says so: "With no sound device in POOL.CFG the game stays silent whatever this says", and the EMS note shown above.

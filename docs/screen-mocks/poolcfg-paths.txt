Color Key:
    GAME NAME           WHITE ON BLUE
    DATA PATH/SAVE PATH LIGHT GRAY ON BLUE
    PATH VALUE          YELLOW ON BLUE (A LONG ONE CUT AT THE LEFT WITH "...", AS DrawInfo DOES)
    HIGHLIGHTED PATH    BLACK ON CYAN
    CHANGED PATH        WHITE ON BLUE, WITH A "*" AFTER IT
    EDIT FIELD          WHITE ON BLACK, BRACKETS LIGHT GRAY, CURSOR SHOWN (UNDERLINE INSERTING, BLOCK OVERWRITING)
    NOTE TEXT           LIGHT CYAN ON BLUE
    ERROR BOX           WHITE ON RED, FRAME YELLOW; THE PATH LIGHT GRAY ON RED

Command Key:
    UP / DOWN           UP, DOWN, HOME, END (THE EIGHT PATHS)
    EDIT                ENTER, OR TYPING A CHARACTER (STARTS THE EDIT WITH IT)
    DEFAULT             F5 (POOL: THE GAME FOLDER AND ITS SAVE\; THE OTHERS: C:\CURSE\ ... AS NOW)
    BACK                ESC
    SAVE AND EXIT       F10
  While editing:
    MOVE                LEFT, RIGHT, HOME, END
    DELETE              DEL, BACKSPACE
    INSERT/OVERWRITE    INS
    ACCEPT              ENTER (CHECKED; SEE THE RULES BELOW)
    CANCEL              ESC (THE OLD PATH BACK)
  Error box:
    DISMISS             ANY KEY (BACK TO THE EDIT, TEXT KEPT, CURSOR AT ITS END)

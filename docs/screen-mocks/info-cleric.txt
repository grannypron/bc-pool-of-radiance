INFO: SAVES STATS KILLS THIEF CLER EXIT

The Cleric page shows the character's effective cleric level and the result used against each kind of undead. The
values are the game's turning table for that level: D destroys automatically, T turns automatically, and a number is
the minimum result required on the turning roll. An unavailable result would be shown as a dash.

CLER is used instead of CLERIC so that both class-information pages fit on the 40-column menu at once. THIEF appears
only when the character has a usable thief level; CLER appears only when the character has a usable cleric level.

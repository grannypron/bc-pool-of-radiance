CAST: CAST INFO EXIT

The character heading is the same on every spell-selection screen. Cast uses rows 4 through 21 for its list. Row 22
is left blank, and the highlighted spell's summary is always shown on row 23, directly above the bottom border.

This example fits on one page, so Next and Prev are absent. When the list is longer than its viewport, the bottom line
is:

    CAST: CAST INFO NEXT PREV EXIT

Color Key:
    CHARACTER HEADING   CYAN
    LEVEL HEADING       MAGENTA
    SPELL NAME          GREEN
    HIGHLIGHTED SPELL   WHITE
    SUMMARY LINE        GREEN
    CAST:               MAGENTA

Command Key:
    CAST                C / ENTER
    INFO                I
    NEXT                N / PAGE DOWN (only when the list has another page)
    PREV                P / PAGE UP (only when the list has another page)
    EXIT                E / ESCAPE

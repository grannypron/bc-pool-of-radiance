SPELL: NEXT PREV EXIT

The page covers the list window (rows 3 to 22) and leaves the list's heading. Rows 6 to 12 hold the figures, values
from column 15 (24 columns); rows 14 to 22 the description (SpellTxt), up to 9 lines of 36 columns. A spell read from
a scroll shows CAST BY  A SCROLL, LEVEL 6. CASTING TIME is AT ONCE, or LATER: -N INITIATIVE for a spell that goes off
later in the round; a spell cast only in camp has none. With one spell on the list the bottom line is SPELL: EXIT.

Color Key:
    SPELL NAME          WHITE
    CLASS AND LEVEL     GREEN
    FIGURE NAME         GREEN
    FIGURE VALUE        WHITE
    CASTER NAME         CYAN (the name's own status color)
    DESCRIPTION         GREEN
    SPELL:              MAGENTA

Command Key:
    NEXT                N / PAGE DOWN / DOWN ARROW (wraps to the first)
    PREV                P / PAGE UP / UP ARROW (wraps to the last)
    EXIT                E / ESCAPE (back to the list, on the spell shown last)
